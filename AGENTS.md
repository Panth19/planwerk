# AGENTS.md

Instructions for any coding agent (Codex, Cursor, Aider, Claude Code, ...).
Claude Code reads CLAUDE.md, which is the long version of this file. Both say the same.

**What this is:** a German Sozialplan (severance plan) calculator. Python engine, a JavaScript
mirror for the browser, an Excel export with live formulas, an MCP server and an assistant.

**Before you finish any task:** `python3 -m pytest -q` must pass.

**Rules that are not up for debate**

1. `planwerk/engine.py`, `web/engine.js` and the formulas in `planwerk/excel.py` implement the
   same rules and must produce identical results. Change all three together. The parity tests
   compare floats with `==`; never relax them.
2. No real client data anywhere in the repo, logs or prompts. Only `data/sample_case.json`,
   which is synthetic and generated by `scripts/make_sample.py`.
3. Language models never compute amounts. They call the engine.
4. The Sozialplan text in `web/index.html` (German and English) must match the engine.
5. Read `docs/RULES.md` before changing a calculation rule.

**Layout:** `planwerk/` Python package, `web/` browser app, `tests/` pytest suite,
`scripts/` release, deploy, rollback, sample data, `.claude/` hooks and subagents.
